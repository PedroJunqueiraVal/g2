## Seção 1 - Visão geral:

**Tema:**

Site de venda de alimentos para ambiente universitário

**Motivação:**

A motivação para o desenvolvmento desse sistema nasce do carecimento de uma ferramenta para organizar o comércio interno no ambiente acadêmico, garantindo o controle rigoroso de prazos e histórico de vendas.

---

## Seção 2 - Plano:

**Objetivo geral:**

Desenvolver um site que simule um marketplace de compra e venda de alimentos, inspirado em platadormas como IFood e 99. O projeto permite o usuário cadastrar o alimento, consultar alimentos disponiveis, a seleção de itens para o carrinho e as escolhas para o metodo de pagamento e finalização da compra.

**Objetivos específicos:**
* Implementar um sistema de cadastro de usuários com com nome, número de celular e seus meios de pagamento.

* Criar uma interface que exiba o tipo de comida (doce ou salgado).

* Automatizar o controle de entrada e saida em estoque de alimentos, permitindo o acompanhamento em tempo real a quantidade disponível.

* Aplicar metodos que facilitem na clareza entre vendedor e comprador, com notificações de confirmação de compra, pagamento e se esta quase faltando produto em estoque.

* Implementar um sistema para o cadastro de informações críticas como data de produção e vencimento dos produtos e consulta ao registro de vendas.
